# Game Build Inspector

**Publisher:** HK Lab Studio  
**Version:** 0.1.2  
**Type:** HTML5 & WebGL game-build preflight utility  
**Release status:** Released

Game Build Inspector is a local browser-based utility for checking HTML5 and WebGL game builds before publishing.

## Publishing profiles

- Generic Web
- itch.io
- Newgrounds
- CrazyGames

## Engine detection

Validated detection includes:

- Godot
- Unity WebGL
- GDevelop
- Construct
- GameMaker HTML5
- Generic HTML5 / JavaScript

## Workflow

1. Load a game-build ZIP locally.
2. Inspect packaging, paths, references and platform requirements.
3. Review PASS, WARN and FAIL results.
4. Apply supported deterministic safe repairs.
5. Export and rescan the repaired ZIP.
6. Export a standalone HTML inspection report.

## Product characteristics

- Local-only browser analysis
- No mandatory uploads
- No account required
- No subscription
- Platform-specific technical checks
- Deterministic safe repair where supported
- Report export

Static inspection does not guarantee marketplace acceptance or runtime game behaviour.

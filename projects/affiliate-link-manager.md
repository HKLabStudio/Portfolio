# Affiliate Link Manager

**Publisher:** HK Lab Studio

**Type:** Framer Plugin  
**Platform:** Framer  
**Release status:** Released

Affiliate Link Manager v1.1.0 is a Framer plugin for auditing supported affiliate and referral links, reviewing proposed corrections, and safely applying supported fixes with Pro.

## Overview

The plugin helps creators define affiliate rules, scan supported affiliate and referral links, review findings, and make supported corrections only when they are ready.

## Key features

- Define affiliate rules
- Scan supported affiliate and referral links
- Review findings and proposed corrections
- Navigate to supported Framer layers
- Apply supported corrections with Pro
- Final confirmation before mutation
- Permission-aware Apply flow
- Undo the latest verified batch
